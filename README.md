# Serial Sensor UI

이 저장소는 시리얼 센서 데이터를 브라우저에서 읽어 UI 요소를 움직이는 간단한 데모입니다. 설치 없이 파일을 브라우저로 열어 사용합니다.

## 요구사항
- Chromium 기반 브라우저 (Chrome, Edge 등)
- 센서/마이크로컨트롤러가 `9600 baud`로 `x,y` 형식의 텍스트를 한 줄씩 전송 (예: `123,45`)

## 실행 방법
1. `index.html` 파일을 Chrome/Edge에서 엽니다. (로컬 파일도 허용되지만, 일부 환경에서는 `localhost`에서 열어야 권한 요청이 잘 동작합니다.)
2. "시리얼 연결" 버튼을 누르고 장치를 선택합니다.
3. 센서를 움직이면 사각형 영역 안의 파란 점이 함께 움직입니다.
4. 연결 해제를 원하면 "연결 해제" 버튼을 누르세요.

## 데이터 포맷
- 각 줄: `x,y` (개행으로 구분)  
- `x`, `y`는 숫자. 범위는 자유입니다. UI가 자동으로 범위를 학습하여 스케일링합니다.
- 노이즈를 줄이기 위해 이동 평균(짧은 히스토리)을 적용합니다.

## 문제 해결
- 브라우저가 "이 브라우저는 Web Serial을 지원하지 않습니다"라고 표시되면 Chrome/Edge 최신 버전을 사용하세요.
- 권한 창이 뜨지 않으면 `localhost` 혹은 HTTPS 환경에서 열어보세요.
- 데이터가 `알 수 없는 데이터`로 표시되면 전송 문자열이 `x,y` 형식인지 확인하세요.

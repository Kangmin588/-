# SensorSky (Accelerometer-driven Planetarium)

- 정적 웹앱: 모바일의 가속도/자이로(디바이스 방향)와 위치를 사용해 하늘을 실시간으로 회전합니다.
- 데스크톱에선 데모 모드(마우스 드래그)로 체험 가능합니다.

## 실행 방법

1. 간단한 정적 서버로 실행합니다. 예시:

```bash
python3 -m http.server 8080
```

2. 브라우저에서 `http://localhost:8080/sky-sensor-app/` 접속
3. 모바일에선 주소로 접속 후 "센서 활성화"를 누르고 권한을 허용하세요 (iOS는 반드시 사용자 제스처 필요)

## 기능

- DeviceOrientation: 기기 방향에 따라 카메라가 회전
- Geolocation: 관측지 좌표 자동 설정(거부 시 서울 기본값)
- 북쪽 보정: 현재 보는 방향을 북쪽(방위각 0°)으로 보정
- 방위각 보정 슬라이더: 수동으로 편차를 조정

## 주의사항

- 실제 천체 시뮬레이션의 정밀도는 데모 수준으로, 별자리·행성·달·은하 등은 미포함입니다.
- 모바일 브라우저의 센서/나침반 오차가 있을 수 있습니다. 보정 기능을 사용하세요.
